# Наша річниця — вінтажний цифровий scrapbook

## Що є в шаблоні
- Вінтажний папір, Polaroid-рамки та адаптивний дизайн
- Лічильник часу разом
- Історія стосунків
- Галерея з відкриттям фото у великому форматі
- Інтерактивні конверти з листами
- Демонстраційний пароль для таємного листа
- Кнопка музики
- Місце для QR-коду, який додається після публікації

## 1. Запуск локально
1. Розпакуй архів.
2. Відкрий папку у Visual Studio Code.
3. Відкрий `index.html` у браузері або встанови розширення Live Server і натисни Go Live.

## 2. Налаштування дати й пароля
Відкрий `script.js` та відредагуй на початку:
- `START_DATE` — дата початку стосунків у форматі `YYYY-MM-DDTHH:MM:SS`
- `SECRET_PASSWORD` — ваше демонстраційне слово-пароль

Цей пароль НЕ є справжнім захистом: його можна побачити у JavaScript, а текст листа — у HTML. Не використовуй цей режим для чутливих матеріалів.

## 3. Додавання фото вручну
1. Поклади фото обкладинки в `photos/cover.jpg`.
2. Додай `photos/photo-1.jpg`, `photos/photo-2.jpg`, `photos/photo-3.jpg`.
3. Щоб додати ще одну картку, скопіюй у `index.html` один блок `<figure class="polaroid ...">...</figure>` у секції `gallery` і зміни ім'я файлу та підпис.
4. Під час перевірки файли мають бути саме в папці `photos`.
5. Після додавання/заміни фото повторно завантаж зміни до репозиторію, якщо сайт опублікований.

## 4. Додавання музики
Додай аудіофайл, який маєш право використовувати, у `music/our-song.mp3`. Музика запускається лише після натискання кнопки — це звична поведінка браузерів.

## 5. Публікація через GitHub Pages
1. Створи репозиторій на https://github.com/.
2. Завантаж `index.html`, `style.css`, `script.js`, `photos/` та `music/`.
3. У репозиторії відкрий Settings → Pages.
4. Вибери Deploy from a branch, гілку `main`, папку `/ (root)` і натисни Save.
5. Дочекайся адреси, яку покаже GitHub Pages, і протестуй сайт з телефона та в режимі інкогніто.

## 6. QR-код
1. Після публікації скопіюй повну HTTPS-адресу.
2. Відкрий https://www.qrcode-monkey.com/ і створи QR-код типу URL.
3. Завантаж його як PNG.
4. Додай файл у `photos/qr-code.png`.
5. За бажанням заміни у секції `qr` блок `<div class="qr-placeholder">...</div>` на `<img src="photos/qr-code.png" alt="QR-код нашого альбому">` і додай CSS для потрібного розміру.
6. Відскануй QR іншим телефоном до друку.

## Важливо
Проєкт не опубліковано автоматично. Це набір файлів для локального запуску та самостійної публікації.
